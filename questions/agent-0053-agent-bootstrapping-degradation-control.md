## 问题

当一个 Agent 能生成新的 Agent（自举 / meta-agent，甚至改自己），一代代传下去很容易「代际退化」——能力越传越弱、错误越滚越多，像复印件的复印件。如何防止这种能力退化与错误累积？

## 答案

> 🤖 AI 答案 · 模型：Claude-Opus-4.8 · 回答 2026-08-06

**先认清退化机制。** 自举的风险和「模型用自己生成的数据训练自己」同源——**model collapse / 回声室**：每一代都以上一代为蓝本，误差、偏见、盲区被继承并放大，还会丢掉多样性；没有外部真值校准，就是拿复印件复印，越印越糊。所以防退化的核心是：**别让「上一代 Agent」成为唯一的真理来源，每一代都必须过一道锚定在客观标准上的独立关卡。**

```
         ┌───────── 信任根（不可被后代篡改）─────────┐
         │ 稳定模板/骨架 · 评测集(客观真值) · 安全护栏 │
         └───────────────────┬───────────────────────┘
  Gen N ──生成──► Gen N+1 候选 ──► [评测门禁] ──通过──► 上线
     ▲                              │不达标            │
     │                              ▼                  ▼
     └───────── 版本回滚 ◄──── 人工审核(高风险) ── 全程审计
```

**五道防线：**

1. **稳定模板/骨架（别每代重造轮子）。** 把已验证的结构、工具接线、护栏、系统提示沉淀成**受版本控制的模板**，新 Agent 是「模板 + 少量特化」，而非从零由上一代自由发挥。骨架不参与代际漂移，退化面被限制在薄薄的特化层。

2. **评测门禁（关键，锚定客观真值）。** 每个新生成的 Agent 必须跑一套**固定的、外部维护的评测集**（golden cases + 回归 + badcase），达标才准上线——这是打破回声室的那把尺子，因为它不来自上一代、不会被后代改写。指标回退就拦下。

3. **人工审核（高风险代际）。** 涉及权限、能力扩张、改护栏的自举变更走人工 review；不是每代都审，而是按风险分级抽审 + 强制审关键节点。

4. **版本回滚 + 血缘。** 每代 Agent 版本化、记录「谁由谁生成、改了什么」的血缘（provenance）；发现某代退化，能快速回滚到已知良好版本，并沿血缘定位问题引入点。

5. **信任根隔离（防错误自我固化）。** 评测集、模板、安全护栏、审计这套「裁判系统」必须**放在后代 Agent 改不到的地方**——若能被自举链自己修改，等于让考生改考卷，退化会被系统性掩盖。裁判与选手隔离，是所有防线的地基。

**一句话：** 防代际退化 = **稳定模板限制漂移面 + 外部评测集当客观关卡 + 高风险人工审 + 版本回滚可追溯 + 信任根隔离防自我固化**。核心一句——**每一代都要对着「不由它自己产生、也改不动」的客观标准过关，而不是只对着上一代自我确认。**

## 延伸 / 追问

**追问：评测门禁本身会不会过时——新 Agent 学会「应试」通过评测，实际能力却在退化（Goodhart's law）？**

会，这是最隐蔽的失败：**当评测集变成被优化的目标，它就不再是好的度量**。防法是让「尺子」保持活的、不可被套利。① **评测集持续演进 + 保留 holdout**：定期注入新 case、把线上真实失败回灌为新用例，并留一部分**从不公开、只用于终审**的隐藏集，让「刷分」无从针对。② **多维度而非单指标**：能力、安全、成本、鲁棒性分开卡，避免优化一个指标牺牲其他；对抗性/边界用例专门测。③ **对齐真实产出而非代理指标**：尽量用「任务是否真的完成、线上是否真的更好」这类结果指标，辅以人工抽检校准，别只信自动分。④ **裁判独立**：评测由人/独立系统维护，不进自举链的可改范围（同信任根隔离）。本质是把评测当成需要持续投入维护的「活基础设施」，而非一次写死的固定关卡——一旦评测停滞，Goodhart 就会把门禁变成退化的遮羞布。
