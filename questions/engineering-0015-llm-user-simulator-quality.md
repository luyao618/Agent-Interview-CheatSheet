## 问题

用 LLM 模拟用户来跑多轮对话评测，能低成本放大样本量，但模拟用户往往「太好说话」——表达清晰、一次讲完、不带情绪、不出异常，导致 Agent 分数虚高。如何验证模拟用户本身可靠？

## 答案

> 🤖 AI 答案 · 模型：Claude-Opus-4.8 · 回答 2026-08-12

**先认清风险：模拟用户是评测链路上的「未标定仪器」。** Agent 的分数 = 真实能力 × 模拟用户的保真度。模拟器若系统性偏简单，测出来的是「Agent 应付理想用户的能力」，与线上表现脱钩。所以模拟器必须**像被测系统一样被评测**。

```
真实用户日志（真值锚）
      │ 对照
      ▼
┌─ 模拟用户 ─┐   ①行为分布对齐  → 轮数/澄清率/情绪占比
│  (待验证)  │   ②难度覆盖度    → 边缘场景是否真出现
└─────┬─────┘   ③判别性        → 人能否分辨真人/模拟
      │ 驱动     ④区分度        → 已知强弱 Agent 能否拉开
      ▼
   被测 Agent ──► 分数 ──对照──► 线上真实指标（收敛效度）
```

**一、用真实日志做真值锚，比对行为分布。** 从线上抽样人工标注：平均轮数、澄清提问率、信息一次性给全的比例、情绪/不满出现频次、中途改需求率、离题率。模拟器跑同样场景后统计同一组指标，逐项比对分布（而非均值）。**分布偏移即失真**——最典型的是模拟器轮数偏短、澄清率偏低。

**二、显式注入被漏掉的四类行为。** 默认 prompt 出不来这些，必须做成**可配置的 persona 维度**并按真实占比采样：① **情绪**：不耐烦、质疑、重复抱怨；② **模糊表达**：指代不清、口语化、错别字、说反话；③ **渐进式信息透露**：关键约束（预算、时间、账号状态）故意留到第 3 轮才说，甚至要 Agent 主动问才给；④ **异常行为**：中途改主意、答非所问、提供矛盾信息、要求做越界的事。

**三、判别性检验（图灵式抽检）。** 让标注员在混合的真人 / 模拟对话里判断哪些是模拟——**接近随机（≈50%）才算保真**；能一眼认出，说明存在可被 Agent「学会」的模式化痕迹。

**四、区分度与收敛效度（最关键）。** 拿**已知强弱的若干 Agent 版本**跑模拟评测：好模拟器应复现出与人工评测/线上指标**一致的排序**；若强弱 Agent 都得高分（天花板效应），说明模拟太温和、没有区分力。再看模拟分与线上真实指标（转人工率、任务完成率）的相关性——这是模拟器可用性的最终判据。

**五、防自我偏好与漂移。** 模拟用户、被测 Agent、Judge **尽量异源**，避免同源模型互相「对暗号」刷高分；模拟器 prompt 与模型版本要**版本化**，每次换版做回归对比，防止评测基线悄悄漂移。

**一句话：** 模拟用户必须先过「**对齐真实分布 + 覆盖边缘行为 + 人难分辨 + 能拉开强弱 Agent**」四关——**测不出差距的模拟用户，不是评测工具，是安慰剂**。

## 延伸 / 追问

**追问：模拟用户和真人的差距永远消不掉，那它到底该用在什么位置？**

定位成**回归筛子，不是验收标尺**。① **用途分层**：模拟评测适合高频回归——改 prompt / 换模型后跑几百条，快速抓「明显变差」，靠的是**相对比较**（同一模拟器下的版本差），不是绝对分。绝对结论仍需人工评测或线上 A/B 兜底。② **只信趋势与差值**：同一版模拟器 + 同一批场景下的分数**变化**有意义；跨模拟器版本的绝对分不可比，所以模拟器必须锁版本，换版时用旧版跑一次做等值化。③ **兜底闭环**：定期抽样模拟对话做人工复核，并把线上新出现的真实失败案例回灌成新场景，让模拟器跟着真实分布演进。④ **明确失效边界**：模拟器测不了真实情绪强度、跨会话长期记忆、多方协作等场景，这些直接标注为「不在模拟覆盖范围」，别用它出结论。核心：**把模拟当廉价的高频信号，把人工留在验收与校准位上**。
