## 更新素材

1. 使用独立浏览器会话打开线上站点，首页保持没有历史作答的初始状态。
2. 按表中页面与视口尺寸拍摄；等待页面和题目阅读区加载完成。
3. 在 `agent-0008` 和 `agent-0025` 中填写演示回答，等待「已自动保存」，再拍摄作答页与「我的回答」。
4. 保持参考答案收起、输入框失焦；确认手机端没有横向溢出。
5. 覆盖对应 PNG，更新本文件的日期与尺寸，并检查根目录 README 的图片展示。
